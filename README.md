# عبدالحكيم للكهرباء والإنارة الحديثة

موقع عربي متعدد الصفحات منشور على [Vercel](https://abdulhakim-lighting-riyadh.vercel.app/). يعرض مجالات الإنارة والكهرباء وعنوان الفلاح في الرياض.

## البيانات

- الاسم التجاري مأخوذ من الرابط الذي قدمه صاحب الطلب. صفحة ملف Google لم تكن متاحة للتحقق المباشر بسبب تحدي التصفح.
- العنوان `2870 شارع الخطابة، 6217، الفلاح، الرياض 13314` ورابط نقطة الخرائط مقدمان من صاحب الطلب لاستخدامهما عند تحديث الملف التجاري. لم يتأكد بعد تطابقهما مع النسخة الحالية للملف.
- رقم الهاتف والواتساب وساعات العمل والصور والتقييمات لم يتم التحقق منها، ولذلك لم تُنشر بيانات مفترضة.
- صفحات المجالات تصف أسئلة الاختيار ولا تؤكد توافر أصناف محددة أو أسعارها.
- بعد الحصول على الرقم، حدّث `lib/site.ts` وأظهر أزرار الاتصال وواتساب في الواجهة. وبعد الحصول على صور أصلية من النشاط، أضفها إلى `public/images` مع نص بديل صحيح.
- خط الموقع العربي Noto Sans Arabic محلي التحميل عبر الحزمة `@fontsource-variable/noto-sans-arabic` المرخصة برخصة OFL.

## التشغيل

```bash
npm install
npm run dev
npm run build
```

عند تغيير نطاق Vercel الافتراضي عيّن `SITE_URL` إلى النطاق النهائي ثم أعد النشر لتتطابق روابط canonical وsitemap وJSON-LD.
