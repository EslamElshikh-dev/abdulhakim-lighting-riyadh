# عبدالحكيم للكهرباء والإنارة الحديثة

موقع عربي متعدد الصفحات، جاهز للنشر على Vercel. صُمم لعرض مجالات الإنارة والكهرباء وعنوان حي الفلاح في الرياض.

## البيانات

- العنوان ورابط نقطة الخرائط مقدمان من صاحب الطلب، مع نية تحديث الملف التجاري بهما.
- رقم الهاتف والواتساب وصور الملف التجاري والخدمات التفصيلية لم يتم التحقق منها بسبب حظر Google للمتصفح، ولذلك لم تُنشر بيانات مفترضة.
- صفحات المجالات تصف أسئلة الاختيار ولا تؤكد توافر أصناف محددة أو أسعارها.
- بعد الحصول على الرقم، حدّث `lib/site.ts` وأظهر أزرار الاتصال وواتساب في الواجهة. وبعد الحصول على صور أصلية من النشاط، أضفها إلى `public/images` مع نص بديل صحيح.

## التشغيل

```bash
npm install
npm run dev
npm run build
```

عند تغيير نطاق Vercel الافتراضي عيّن `SITE_URL` إلى النطاق النهائي ثم أعد النشر لتتطابق روابط canonical وsitemap وJSON-LD.
