# عبدالحكيم للكهرباء والإنارة الحديثة

موقع عربي لخدمات الكهرباء والإنارة في مدينة الرياض، منشور على [Vercel](https://abdulhakim-lighting-riyadh.vercel.app/).

## البيانات العامة

- الاسم ورقم الهاتف ونطاق الخدمة وساعات العمل روجعت في واجهة الإدارة الفعلية للملف التجاري بتاريخ 7 أكتوبر 2026.
- رقم التواصل: 0532305309. الاتصال يستخدم الصيغة الدولية +966532305309، ورابط واتساب يستخدم الرقم نفسه.
- نطاق الخدمة مدينة الرياض، والملف التجاري يعرض العمل على مدار الساعة.
- عنوان التشغيل مستخدم للتحقق داخل Google فقط؛ لا ينشر في الموقع أو JSON-LD أو هذا المستودع.
- روجعت الواجهة لتعرض التواصل وتنسيق الخدمة في موقع العميل بدل الاتجاهات إلى عنوان قديم.
- السكيما: Electrician وWebSite وصفحات WebPage وAboutPage وContactPage وFAQPage، وخدمات Service ومسارات BreadcrumbList. يُنشر عنوان المدينة العام فقط دون شارع أو رمز بريدي أو إحداثيات.
- لا توجد أسعار أو مخزون أو تقييمات أو ادعاءات تحقق مفترضة. الأسئلة في FAQPage تطابق الإجابات المعروضة.
- كود Search Console محفوظ. روابط canonical وخريطة الموقع تستخدم النطاق النهائي.
- خط Noto Sans Arabic محلي عبر @fontsource-variable/noto-sans-arabic المرخص برخصة OFL.

## التشغيل

```bash
npm ci
npm run dev
npm run build
```

عند تغيير النطاق، عيّن SITE_URL وأعد النشر لتتطابق الروابط القانونية وخريطة الموقع وJSON-LD.
